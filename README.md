# Warframe-Market-Searcher
給予繁體中文使用者的WarframeMarket遍歷所有商品，並在GoogleSheet當中進行檢視的工具。

這是我在 GitHub 上建立的第一個專案，目前仍在開發中，排版與內容會持續改進。

專案目前開發進度約 50%，功能仍在持續完善中。

## 功能列表
- [x] 自 WFM 匯入 API 並進行資料解析與篩選。
- [x] 獲取可交易物品名稱總表。
- [x] 獲取特定商品當前在線買家最高出價。
- [x] MOD 及賦能的 0 級和滿級在線買家最高出價。(2026/05/04完成)
- [x] 紀錄每次匯入時的價格，追蹤商品價格浮動。(2026/05/12完成)
- [ ] 將試算表與 Colab 程式碼進行可複製規範化。
- [ ] 提供可複製的 Google 試算表與 Colab 程式碼範本，並附上完整教學，讓其他使用者能直接套用與運行。
- [ ] 將工具延伸為完整網站，提供更直覺的操作與檢視介面。
